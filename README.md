# Python Healthcare Basics

This repository contains my first small Python exercises related to healthcare data.

I am using this project to build strong foundations in programming, data science, and AI for Healthcare step by step.

## Project 1: BMI Calculator

The first exercise is a simple Body Mass Index calculator.

It asks for:

- Weight in kilograms
- Height in meters

Then it calculates BMI and gives a basic category.

## Project 2: Heart Rate Zones

The second exercise estimates basic heart rate training zones from age.

It asks for:

- Age

Then it estimates maximum heart rate and gives simple zone ranges.

## Why This Project Matters

Even simple healthcare-related projects help me practice:

- Python basics
- User input
- Functions
- Conditional logic
- Clear documentation
- Basic healthcare formulas
